# 🎨 VS Code Settings

Minhas configurações do VS Code, com CSS e JavaScript customizados para deixar a interface mais limpa e com cara própria.

![VS Code](https://img.shields.io/badge/VS_Code-007ACC?style=for-the-badge&logo=visualstudiocode&logoColor=white) ![CSS](https://img.shields.io/badge/CSS-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## 📦 Arquivos

| Arquivo | O que faz |
|---|---|
| `settings.json` | Configurações do editor: fonte JetBrainsMono Nerd Font (16), tema Vim Dark Medium, formatar ao salvar, organizar imports, rolagem e cursor suaves, Tailwind CSS em HTML/JS/TS, barra de título customizada |
| `custom.css` | Sombras no editor e na sidebar, item selecionado do Explorer, scrollbar, Command Palette e listas redesenhadas |
| `custom.js` | Aplica um desfoque (blur) no fundo quando a Command Palette está aberta |

## 🚀 Como usar

1. Copie o conteúdo de `settings.json` para o seu `settings.json` do usuário (**Ctrl+Shift+P → Preferences: Open User Settings (JSON)**).
2. Para `custom.css` e `custom.js`, use uma extensão que carregue CSS/JS customizado no VS Code (por exemplo, *Custom CSS and JS Loader*) e aponte para esses arquivos.
3. Instale as fontes e o tema citados, ou troque pelos seus.

> ⚠️ Extensões que injetam CSS/JS modificam o VS Code e podem exibir o aviso de instalação “corrompida”. Isso é esperado.
